**Легковесный AFK-бот для серверов Minecraft Java Edition, разработанный специально для Aternos.**  
Создан на базе Mineflayer; он автоматически переподключается, имитирует активность игрока и поддерживает серверные пароли (/register, /login).

## **Особенности**

- **Авто-подключение и переподключение** — заходит на сервер автоматически. Если бота кикнули или сервер перезагрузился, он подождет 5 секунд и переподключится.
- **Anti-AFK** — каждые 2 секунды бот двигается вперед/назад, прыгает или осматривается. Это предотвращает кик за бездействие.
- **Поддержка паролей** — автоматически отправляет команды `/register` и `/login` при появлении (опционально).
- **Легкость** — всего одна зависимость (mineflayer) и простой конфигурационный файл.
- **Автоматическое определение версии** — бот сам определяет версию Minecraft сервера.

## **Установка**

*Клонируйте репозиторий*
```bash
git clone https://github.com/AngelKlear-2/mabfa.git
cd mabfa
```

*Установите зависимости*

  ```bash
npm install
  ```

## **Настройка бота**

Отредактируйте файл `config.json`, указав данные вашего сервера Aternos:
```json
   {
     "host": "example.aternos.me",
     "port": 25565,
     "username": "AFKbot",
     "viewDistance": 5,
     "enablePassword": false,
     "password": ""
   }
```

   **Описание полей:**  
   ```txt
   host – Адрес вашего сервера Aternos  
   port – Порт сервера
   username – Игровое имя бота  
   viewDistance – Чем ниже значение, тем меньше нагрузка на сервер  
   enablePassword – Установите true, если на сервере требуются /register и /login  
   password – Ваш пароль (игнорируется, если enablePassword установлено в false)
   ```
   *Важно для Aternos:* Сервер должен быть запущен вручную (или поддерживаться в сети сторонним сервисом). Бот не может самостоятельно включить выключенный сервер.

*Запуск бота*

```bash
node bot.js
```
*или*
```bash
npm start
```
   Чтобы бот работал 24/7 на VPS или Raspberry Pi:
   ```bash
   npm install -g pm2
   pm2 start bot.js --name mabfa
   pm2 save
   pm2 startup
   ```
*Остановка бота* — нажмите Ctrl+C или введите `pm2 stop mabfa`.

## **Как это работает**

- При запуске бот подключается к указанному `host:port`.
- После появления в мире запускается интервал (каждые 2 секунды), который по очереди заставляет бота идти вперед, назад, прыгать или вращать головой.
- Если соединение обрывается (сервер оффлайн, кик, ошибка), бот ждет 5 секунд и пробует подключиться снова.
- Если `enablePassword: true`, бот отправляет `/register <пароль>` через одну секунду после спавна, а затем `/login <пароль>` еще через полсекунды.

## **Решение проблем**

| Проблема | Решение |
|-------|----------|
| *ECONNREFUSED* | Ваш сервер Aternos выключен. Запустите его через панель Aternos. |
| *Бот не двигается* | Некоторые античит-плагины блокируют резкие движения. Увеличьте интервал в `bot.js` (значение 2000 в `setInterval`). |
| *Бот не отправляет пароль* | Убедитесь, что `enablePassword: true` и поле `password` не пустое. Если сервер тормозит, увеличьте задержку в `bot.js` (значение 1000 в `setTimeout`). |
| *Ошибка Invalid username* | Бот использует `auth: 'offline'` (зашито в коде). Он работает с любым ником — вход через Microsoft не требуется. |
